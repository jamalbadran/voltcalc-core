# VoltCalc-Core ⚡

An open-source, dependency-free Python calculation engine for electrical installations, cable sizing, voltage drop analysis, and power factor correction.

Built specifically to provide vocational students, electrical technicians, and engineering apprentices with transparent, verifiable calculation models without requiring commercial CAD software or proprietary tools.

## Features

- **Voltage Drop Analysis:** Accurate calculation for single-phase (2-wire) and three-phase (3/4-wire) distribution lines.
- **Conductor Sizing:** Automated recommendation engine against standard metric cable cross-sections (1.5mm² to 240mm²).
- **Power Factor Correction:** Precise kVAR sizing to improve efficiency from inductive industrial loads.
- **Zero External Dependencies:** Runs on standard Python 3.8+ runtime.
